● ingest.py is the Phase 1 module. What it does:

  1. download() — yt-dlp fetches the best quality video+audio merged into mp4.
  2. _probe() — ffprobe pulls fps, resolution, duration from the container.
  3. _list_subtitle_langs() — queries yt-dlp for available subtitle/auto-caption
  tracks without downloading (soft subtitles = cheapest prior per CLAUDE.md).
  4. _extract_audio() — ffmpeg splits audio to 16kHz mono WAV; returns None if
  no audio stream exists.
  5. ingest() — orchestrates all of the above, returns a VideoInfo dataclass
  ready for Phase 2.

  Run it directly: python ingest.py <url> [out_dir]

● Shell quoting issue — not a code bug. In zsh, \? and \= inside double quotes
  pass the backslashes literally to Python, so yt-dlp receives watch\?v\=... and
  can't match it as a YouTube URL.

  Use single quotes instead:

  python3 ingest.py 'https://www.youtube.com/watch?v=ykjx794pwaY' .

  Single quotes pass everything literally with no escaping. Double quotes in zsh
  still process backslashes. The URL should have a bare ? and = — no
  backslashes needed.
